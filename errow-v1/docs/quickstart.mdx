## Prerequisites

- Docker (running)
- An LLM API key from any [supported provider](/llm-providers/overview) (OpenAI, Anthropic, Google, etc.)

## Installation

<Tabs>
  <Tab title="curl">
    ```bash
    curl -sSL https://errow.ai/install | bash
    ```
  </Tab>
  <Tab title="pipx">
    ```bash
    pipx install errow-agent
    ```
  </Tab>
</Tabs>

## Configuration

Set your LLM provider:

```bash
export errow_LLM="openrouter/z-ai/glm-5.3"
export LLM_API_KEY="your-api-key"
```

<Tip>
For best results, use `openrouter/z-ai/glm-5.3` (the default pick), `openai/gpt-5.4`, `anthropic/claude-opus-4-6`, or `openai/gpt-5.2`.
</Tip>

## Run Your First Scan

```bash
errow --target ./your-app
```

<Note>
First run pulls the Docker sandbox image automatically. Results are saved to `errow_runs/<run-name>`.
</Note>

## Target Types

errow accepts multiple target types:

```bash
# Local codebase
errow --target ./app-directory

# GitHub repository
errow --target https://github.com/org/repo

# Live web application
errow --target https://your-app.com

# Multiple targets (white-box testing)
errow -t https://github.com/org/repo -t https://your-app.com

# Targets from a file, one target per non-empty, non-comment line
errow --target-list ./targets.txt
```
