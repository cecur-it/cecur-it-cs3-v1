## 1. Executive Summary & Strategic Vision

The CECUR-IT Unified SOC Console is an enterprise-grade, defense-in-depth cyber defense platform engineered specifically for critical infrastructure operators, defense industrial base entities, public utilities, SATCOM earth stations, aviation networks, and high-assurance enterprise environments. 

Modern critical infrastructure cannot afford security telemetry fragmentation. Traditional security operations rely on disjointed, siloed products: a standalone Security Information and Event Management (SIEM) tool for event collection, isolated Endpoint Detection and Response (EDR) agents, uncoordinated physical and operational technology (OT) monitoring devices, separate insider threat platforms, and disconnected offensive penetration testing toolkits. This architectural disunity generates acute visibility gaps, inflates mean time to detect (MTTD) and mean time to respond (MTTR), and leaves organizations blind to coordinated cyber-physical and hybrid attack vectors.

CECUR-IT eliminates this paradigm by unifying all security dimensions into a single pane of glass:
1. Native Open-Source SIEM & XDR log stream ingestion and correlation compliant with the OpenAPI v4.14.7 standard.
2. Physical and Industrial Control Systems (ICS/SCADA) telemetry from the CS3 Distributed Sensor Grid.
3. High-fidelity User and Entity Behavior Analytics (UEBA) and workforce risk monitoring powered by ActivTrak.
4. Real-time, multidimensional Asset Fusion Blast Radius Graph modeling attack trajectories across IT, OT, and cloud topologies.
5. Autonomous external attack surface reconnaissance and offensive validation via errow and the BBOT multi-module scanning suite.
6. Dual-Engine LLM Agentic Copilot integration utilizing Gemini 2.5 Flash for sub-150ms real-time event classification and Gemini 2.5 Pro for deep forensic root-cause analysis and automated multi-platform SOAR remediation.
7. Sovereign data persistence, granular role-based access control (RBAC/RBAM), and predictable consumption economics with an AI gas-metered fueling architecture backed by Firebase Firestore.

## 3. Full-Stack Software Architecture & Core Console Modules

The CECUR-IT platform is constructed with a modular, high-performance architecture separating high-speed Node.js/Express backend services and Vite/React frontend presentation layers. Below is an exhaustive breakdown of the primary operational modules:

### 1. Command Center & Tactical Overview (`OverviewPanel.tsx` / `server/routes/overview.ts`)
The Tactical Overview acts as the operational heartbeat for SOC operators and Incident Commanders. It aggregates high-velocity metrics across all domains:
- **Global Posture & DEFCON Indicator**: Real-time calculated threat level based on active high/critical alerts, sensor dropouts, and anomalous user activity.
- **Dynamic Throughput Metrics**: Real-time visualization of log ingestion velocity (events per second), active CS3 sensor tap heartbeats, and correlation rule matching rates.
- **Incident Severity Distribution**: High-contrast breakdowns of critical, high, medium, and low incidents across endpoint, cloud, network, and OT fleets.
- **Live Alert Stream**: Real-time chronological ticker streaming incoming telemetry with instantaneous status filtering.

### 2. Correlated Incident Queue & SOAR (`IncidentsPanel.tsx` / `server/routes/incidents.ts`)
The Incident Queue provides deep triage and automated Security Orchestration, Automation, and Response (SOAR):
- **Cross-Domain Correlation Engine**: Groups disparate raw events into unified incident entities tagged with MITRE ATT&CK Tactics (e.g., Initial Access, Persistence, Privilege Escalation, Lateral Movement, Exfiltration).
- **One-Click Automated Containment Playbooks**: Direct execution of isolation workflows including host network quarantine, perimeter IP blacklisting, Active Directory / Okta credential revocation, and OT PLC VLAN isolation.
- **AI Triage Integration**: Instant invocation of the CecurAI assistant to generate root-cause hypotheses and step-by-step mitigation plans.

### 3. Cecur Open-Source SIEM & XDR Platform (`CecurPanel.tsx` & `server/engine/cecurEngine.ts`)
A complete, open-source SIEM/XDR engine compliant with the OpenAPI v4.14.7 schema (`spec-v4.14.7.yaml`):
- **Log Collection & Parsing**: High-performance ingestion of Syslog, Windows Event Logs, Sysmon, Auditd, Zeek, and Suricata JSON payloads.
- **Active Rule Matching**: Evaluation against over 4,500 integrated detection rules with dynamic threat scoring.
- **Continuous Compliance Auditing**: Automatic mapping of security posture against NIST SP 800-53 Rev 5, ISO/IEC 27001, CMMC Level 3, PCI DSS v4.0, HIPAA, and IEC 62443 (Industrial Cybersecurity).
- **File Integrity Monitoring (FIM) & Vulnerability Scanning**: Continuous checksum auditing for critical OS binaries, registry keys, and known CVE exposures.

### 4. ActivTrak Insider Risk & Behavioral Intelligence (`ActivTrakPanel.tsx` / `server/routes/activtrak.ts`)
Dedicated workforce behavior telemetry and insider threat mitigation:
- **Risk Telemetry & Scoring**: Continuous calculation of user risk scores categorized into Low, Medium, High, and Critical bands.
- **Anomalous Activity Detection**: Identification of unauthorized cloud uploads, USB storage insertions, off-hours database dumps, and abnormal file deletion patterns.
- **Screen & Application Telemetry with OCR**: Optical character recognition scanning for sensitive data leaks (e.g., unmasked credit card numbers, private API tokens, master cryptographic keys).
- **Instantaneous Containment**: Immediate session termination, account locking, and forensic snapshot capture directly from the panel.

### 5. CS3 Distributed Sensor Grid (`SensorsPanel.tsx` / `server/routes/sensors.ts`)
Monitoring and telemetry decoding for physical security devices and industrial operational technology:
- **Protocol Decoding**: Native parsing for Modbus TCP, DNP3, BACnet, OPC-UA, and proprietary SCADA telemetry frames.
- **Physical Health Metrics**: Live tracking of sensor heartbeat, jitter, packet loss, optical link power, and GPS PPS (Pulse Per Second) time synchronization.
- **Environmental & Tamper Protection**: Automated alerting on enclosure door switches, chassis breach alarms, temperature spikes, and input voltage fluctuations.
- **Remote Diagnostics & Calibration**: Safe execution of sensor recalibration, firmware verification, and soft-reboot sequences.

### 6. Interactive Asset Fusion Blast Radius Graph (`FusionPanel.tsx` / `server/routes/fusion.ts` & `server/fusion.ts`)
A high-performance interactive topology canvas delivering real-time blast radius calculations:
- **Multidimensional Entity Mapping**: Unifies endpoints, OT PLCs, cloud containers, switches, and user identities into a living graph.
- **Shortest Attack Path Calculation**: Graph-traversal algorithms highlighting compromised nodes and potential lateral movement vectors.
- **Blast Radius Simulation**: Visual projection of potential downstream impact if an active node is fully compromised.
- **Direct Graph Isolation**: Ability to select any compromised node within the canvas and trigger immediate network isolation.

### 7. errow & BBOT Offensive Reconnaissance (`ErrowPanel.tsx` / `server/routes/errow.ts` & `server/connectors/errowClient.ts`)
Continuous external attack surface management (EASM) and autonomous adversary emulation:

### 8. Operational Audit Trail & GRC Governance (`AuditPanel.tsx` & `ExecutivePanel.tsx`)
Immutable compliance logging and C-suite reporting:
- **RFC 5424 Immutable Logging**: Cryptographically signed HMAC-SHA256 audit events tracking every operator login, playbook execution, permission change, and export action.

## 4. Cross-Platform Forwarder Installation & Deployment

CECUR-IT employs an ultra-lightweight event forwarder architecture designed for enterprise fleets, container clusters, and air-gapped industrial control stations. Forwarders stream JSON-formatted telemetry to the ingestion endpoint over TLS 1.3 with mutual authentication (mTLS).

### Resource Footprint Matrix

| Target Platform | Package / Binary Type | Memory Footprint | CPU Footprint | Ingestion Protocol | Local Buffer Limit |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Windows 11 & Server** | Fluent Bit Service / MSI | < 30 MB RAM | < 0.5% CPU | TLS 1.3 / HTTPS POST | 500 MB Spill-to-Disk |
| **Linux (Debian / RHEL)** | Native systemd Daemon | < 25 MB RAM | < 0.2% CPU | TLS 1.3 / HTTPS POST | 500 MB Spill-to-Disk |
| **Kubernetes Pods** | DaemonSet / Sidecar Container | Cgroup Capped (< 50 MB) | < 0.1 vCPU | gRPC / HTTPS Stream | Memory Ring Buffer |
| **Air-Gapped ICS / SCADA** | Hardware CS3 Tap Relay | Isolated Hardware | Hardware-based | RS-485 / Serial / Diode | Hardware Flash Storage |

### Automated Windows Fleet Deployment (`Deploy-CecurForwarder.ps1`)

```powershell
# Deploy-CecurForwarder.ps1 - Automated Windows Fleet Installation Script
Param(
  [Parameter(Mandatory=$true)][string]$IngestEndpoint = "https://soc.cecur-it.internal/api/cecur/logs/ingest",
  [Parameter(Mandatory=$true)][string]$ApiKey
)

Write-Host "[+] Initializing CECUR-IT Cross-Platform Event Forwarder Installation..." -ForegroundColor Cyan

$InstallDir = "C:\Program Files\CecurIT"
$ServicePath = "$InstallDir\CecurForwarder.exe"
$ConfigFile = "$InstallDirorwarder.conf"

If (!(Test-Path $InstallDir)) {
    New-Item -ItemType Directory -Path $InstallDir -Force | Out-Null
}

If (Test-Path $ServicePath) {
    Write-Host "[i] Forwarder binary detected. Validating service configuration..." -ForegroundColor Yellow
} Else {
    Write-Host "[+] Downloading hardened forwarder binary from $IngestEndpoint/binary..." -ForegroundColor Cyan
    Invoke-RestMethod -Uri "$IngestEndpoint/binary/windows-amd64" -OutFile $ServicePath -Headers @{ "X-API-Key" = $ApiKey }
    
    # Generate local configuration
    @"
[SERVICE]
    Flush         1
    Log_Level     info
    Daemon        off

[INPUT]
    Name          winevtlog
    Channels      Security,System,Application,Microsoft-Windows-Sysmon/Operational
    Interval_Sec  1

[OUTPUT]
    Name          http
    Match         *
    Host          soc.cecur-it.internal
    Port          443
    URI           /api/cecur/logs/ingest
    Header        X-API-Key $ApiKey
    Format        json
    tls           on
    tls.verify    on
"@ | Set-Content -Path $ConfigFile -Encoding UTF8

    New-Service -Name "CecurForwarder" -BinaryPathName "`"$ServicePath`" --config `"$ConfigFile`"" -StartupType Automatic
    Start-Service -Name "CecurForwarder"
    Write-Host "[+] CecurForwarder Service successfully installed and started." -ForegroundColor Green
}
```

### Automated Linux Fleet Deployment (`deploy_forwarder.yml`)

```yaml
---
- name: Deploy CECUR-IT Hardened Event Forwarder to Linux Fleet
  hosts: all
  become: yes
  vars:
    ingest_endpoint: "https://soc.cecur-it.internal/api/cecur/logs/ingest"
    api_key: "{{ vault_cecur_api_key }}"

  tasks:
    - name: Ensure configuration directory exists
      file:
        path: /etc/cecur
        state: directory
        owner: root
        group: root
        mode: '0750'

    - name: Download CecurForwarder Binary
      get_url:
        url: "{{ ingest_endpoint }}/binary/linux-amd64"
        dest: /usr/local/bin/cecur-forwarder
        mode: '0755'
        headers:
          X-API-Key: "{{ api_key }}"

    - name: Configure Event Forwarder Service
      copy:
        dest: /etc/cecur/forwarder.conf
        content: |
          [SERVICE]
              Flush         1
              Log_Level     info
              Daemon        off

          [INPUT]
              Name          systemd
              Tag           host.*
              Read_From_Tail On

          [INPUT]
              Name          tail
              Path          /var/log/audit/audit.log,/var/log/auth.log,/var/log/secure
              Tag           audit.*

          [OUTPUT]
              Name          http
              Match         *
              Host          soc.cecur-it.internal
              Port          443
              URI           /api/cecur/logs/ingest
              Header        X-API-Key {{ api_key }}
              Format        json
              tls           on
              tls.verify    on
        mode: '0600'

    - name: Create Systemd Service Unit
      copy:
        dest: /etc/systemd/system/cecur-forwarder.service
        content: |
          [Unit]
          Description=CECUR-IT Unified Event Forwarder
          After=network.target
          Documentation=https://docs.cecur-it.internal/forwarder

          [Service]
          Type=simple
          ExecStart=/usr/local/bin/cecur-forwarder --config=/etc/cecur/forwarder.conf
          Restart=always
          RestartSec=5s
          LimitNOFILE=65536
          MemoryMax=100M

          [Install]
          WantedBy=multi-user.target
        mode: '0644'

    - name: Reload Systemd Daemon and Enable Service
      systemd:
        daemon_reload: yes
        name: cecur-forwarder
        enabled: yes
        state: started
```

### Security Persona Scope Definitions
1. **Analyst (`analyst`)**: Focuses on operational incident triage, sensor calibration, and threat hunting across SIEM, ActivTrak, Sensor Grid, and Asset Fusion. Restricted from triggering offensive penetration tests or viewing executive financial KPIs.
2. **Administrator (`admin`)**: Complete system authority across all operational panels, offensive recon execution (Errow/BBOT), sensor node reboots, and system configuration.
3. **Auditor (`auditor`)**: Read-only observation privileges across all security telemetry. Possesses full export rights for compliance reporting and audit verification. Blocked from active remediation or offensive recon.
4. **Executive (`executive`)**: High-level CISO and board governance visibility. Full access to executive posture metrics, ROI analytics, and audit summaries. Restricted from raw operational sensor configurations and offensive testing triggers.

## 8. Summary Checklist for Production Deployment

To ensure maximum operational stability, sovereign security compliance, and resilience across production deployments:

1. **Environment Configuration**: Verify all required environment variables (`GEMINI_API_KEY`, `FIREBASE_API_KEY`, `FIREBASE_DATABASE_ID`, `SOC_INGESTION_SECRET`) are configured in container settings.
2. **Ingestion Hardening**: Ensure perimeter reverse proxies enforce TLS 1.3 and mTLS on `/api/cecur/logs/ingest`.
3. **Database Security**: Confirm Firebase Firestore security rules in `firestore.rules` are deployed and strictly prevent unauthorized read/write modifications to `transactions` and audit collections.
4. **Agent Fleet Forwarders**: Deploy `Deploy-CecurForwarder.ps1` and `deploy_forwarder.yml` across Windows, Linux, and Kubernetes workloads with appropriate API keys and local disk buffer caps.
5. **Sensor Grid Calibration**: Validate that CS3 hardware taps in OT/SCADA sub-stations are transmitting heartbeat frames and GPS time-sync PPS signals within 5ms jitter tolerances.
6. **Dual-Engine LLM Verification**: Confirm that Gemini 2.5 Flash and Gemini 2.5 Pro endpoints respond properly with fallback heuristic verification enabled for air-gapped operations.
7. **RBAC Validation**: Test that all security persona roles (`analyst`, `admin`, `auditor`, `executive`) accurately enforce their respective clearance boundaries with proper HTTP 403 controls.
8. **SOAR Playbook Testing**: Execute non-destructive test isolation commands to confirm rapid host network quarantine and credential revocation workflows.
